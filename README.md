# Monkeytype Autotyper

Плавающая панель-автотайпер для `monkeytype.com`: WPM, jitter, случайная скорость, намеренные ошибки, скрытие окна и горячие клавиши. Работает без `chrome.debugger` — плашки «запустил отладку браузера» нет.

## Файлы

```
monkeytype-autotyper/
├─ extension/
│  ├─ manifest.json      MV3, только storage
│  ├─ content.js         панель, логика, ввод
│  └─ panel.css          стили панели
├─ monkeytype-autotyper.user.js   автономный Tampermonkey-скрипт
└─ README.md
```

## Установка расширения

### Brave

1. `brave://extensions`
2. Включи **Developer mode**.
3. **Load unpacked** → выбери папку `extension`.
4. Открой `https://monkeytype.com` и обнови страницу.

### Microsoft Edge

1. `edge://extensions`
2. Включи **Режим разработчика**.
3. **Загрузить распакованное** → папка `extension`.
4. Обнови monkeytype.

### Chrome

`chrome://extensions` → **Developer mode** → **Load unpacked** → папка `extension`.

После обновления файлов нажми **Reload** у расширения и обнови вкладку monkeytype.

## Установка userscript

1. Установи Tampermonkey в Brave/Edge/Chrome.
2. Создай новый скрипт, вставь содержимое `monkeytype-autotyper.user.js`, сохрани.
3. Обнови monkeytype.

Userscript не требует папки `extension` и работает полностью локально.

## Использование

- **F8** — старт/стоп.
- **F9** — скрыть/показать панель.
- **Start / Stop** — то же самое кнопками.
- **–** в заголовке — скрыть панель. Вернуть — кнопка **MT** справа сверху или F9.
- Панель перетаскивается за заголовок; позиция и настройки сохраняются.
- Перед стартом тест должен быть свежим. Если уже начат — нажми **Tab** (рестарт monkeytype), потом F8.
- Для zen сначала набери/вставь текст, затем Start.

## Настройки

| Настройка | Что делает |
|---|---|
| Speed (WPM) | Базовая скорость, 40–400, шаг 5. |
| Jitter | Случайное отклонение задержки, 0–50%. По умолчанию 15%. |
| Fix wrong chars | Стирать случайно введённый неверный символ и печатать заново. |
| Random WPM | Скорость гуляет в заданном диапазоне. Укажи Min и Max. |
| Make errors | Намеренные ошибки: неверный символ, пауза, Backspace, правильный символ. |
| Errors | Сколько намеренных ошибок сделать за тест. |

Микропаузы (перед первым символом, после пробела, после знаков) добавляются только при WPM ниже 200. На высокой скорости они отключаются, чтобы не съедать темп.

Скрипт каждые 20 символов считает фактический темп и подстраивает задержку. Фактический WPM виден в статусе: `typing · synth · ~385 wpm`.

## Как это работает

**Ввод.** Расширение и userscript используют синтетический ввод:

1. `document.execCommand("insertText", false, char)` — основной путь.
2. Если браузер вернул `false` — прямое изменение `#wordsInput.value` + `InputEvent("input")`.
3. Backspace — `execCommand("delete")` или удаление последнего символа + `InputEvent`.
4. Zen завершается синтетическим `keydown` с `Shift+Enter`.

`chrome.debugger` не используется, поэтому нет инфобара отладки. Monkeytype обрабатывает `beforeinput`/`input`, а не проверяет `isTrusted`, поэтому такой ввод проходит.

**Чтение текста.** `#words .word[data-wordindex]`, внутри — `letter`. Учитываются классы `correct`, `incorrect`, `extra`, `dead`, `nlChar`, `tabChar` и иконки стрелок. Перевод строки определяется по `nlChar` или sibling-элементам `beforeNewline` / `newline`.

**Темп.** База: `60000 / (WPM * 5)` мс на символ. Сверху jitter, паузы, компенсация накладных расходов и автокалибровка.

**Random WPM.** Каждые 0.7–3 секунды выбирается новая цель в диапазоне Min–Max. Джиттер применяется поверх.

**Ошибки.** В начале теста строится план:

- для `time` и custom-time — случайные моменты в пределах 15–85% длительности;
- для `words` / `quote` / custom-words — случайные слова, в каждом выбирается позиция символа.

В намеченной точке печатается неверный символ, затем Backspace и правильный символ. Monkeytype засчитывает исправленную ошибку в статистику. Режим ошибок отключается, если в monkeytype включён `stopOnError` (ввод блокируется на ошибке), `deleteOnError` (monkeytype сам стирает символ) или `confidenceMode: max` (Backspace запрещён).

**Конец теста.** `time` и custom-time считаются бесконечными: скрипт ждёт следующие слова. `words` / `quote` / custom-words — конечные: после последнего слова ждёт завершения теста, при необходимости добивает пробелом.

## Ограничения

- Вкладка должна быть активной, иначе Chrome троттлит таймеры.
- Monkeytype может пометить результат невалидным при WPM выше ~350 (или 420 в words 10) и в слишком коротких тестах.
- При `confidenceMode: max`, включённом `stopOnError` или `deleteOnError` автоисправление и режим ошибок не работают.
- Режим ошибок рассчитан на обычные тесты. В очень коротком тесте часть запланированных ошибок может не успеть сработать.
- Синтетический ввод может не сработать в экзотических funbox-режимах, где monkeytype слушает только `keydown`. В обычных режимах проблем нет.
- После обновления расширения нужно нажать **Reload** в `brave://extensions` / `edge://extensions` и обновить вкладку.

## Диагностика

- Панель не появилась: проверь, что расширение включено и страница именно `https://monkeytype.com`.
- Статус `waiting for test`: тест не готов или уже идёт результат. Нажми Tab и попробуй снова.
- Статус `restart the test first (Tab)`: тест уже начат.
- Статус `input not registering`: monkeytype не принял синтетический ввод; обнови страницу и попробуй снова.
- `backspace blocked`: monkeytype запретил Backspace (`confidenceMode: max`) или включён `deleteOnError`.
- Ошибки не появляются: включи **Make errors**, поставь количество больше 0 и выключи в monkeytype `stopOnError`, `deleteOnError` и `confidenceMode: max`.
